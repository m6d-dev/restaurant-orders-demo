# Онлайн-заказы для ресторанов — демо

Только фронтенд для презентации (Next.js 16 + React 19). Бэкенда нет: данные хранятся в `localStorage` браузера.

## Запуск локально

```bash
npm install
npm run dev        # http://localhost:3000
```

## Страницы

- `/`: лендинг платформы со ссылками на демо
- `/shop`: сайт ресторана «Дастархон». Меню, корзина, районы доставки, оформление заказа, отслеживание статуса, отзывы
- `/admin`: панель ресторана. Заказы, аналитика, отзывы (с ответами), меню и стоп-лист, зоны доставки, настройки сайта
- `/kitchen`: экран кухни для планшета. Колонки «Новые → Готовятся → Готовы к выдаче», таймеры, отметки блюд

Путь заказа: **Новый → Готовится → Готов → В пути → Доставлен** (или «Отклонён» с причиной).

## Как показывать

Откройте `/shop`, `/admin` и `/kitchen` в разных окнах одного браузера:

1. На сайте оформите заказ. Он сразу появится в панели и на кухне.
2. На кухне нажмите «Принять в работу», затем «Готово» и «Отдан курьеру». В панели нажмите «Отметить „Доставлен“». У клиента статус обновляется сам.
3. После доставки клиент ставит оценку. Отзыв появляется в панели, ресторан отвечает, ответ виден на сайте.
4. Выключите блюдо в «Меню и стоп-лист». Оно пропадёт с сайта.
5. Смените цвет бренда в «Настройках сайта». Сайт перекрасится.

На кухне нажмите «Включить звук»: браузер разрешает звук только после нажатия на странице.
«Сбросить демо» (в панели или на лендинге) возвращает исходные данные.

> Синхронизация между окнами работает через `localStorage`, то есть только в одном браузере на одном устройстве.
> У каждого посетителя свои данные. Это демо, а не рабочая система.

## Деплой на Vercel

Docker для Vercel не нужен: Vercel сам собирает Next.js.

1. Залейте проект в GitHub/GitLab.
2. На vercel.com: **Add New → Project**, выберите репозиторий. Настройки оставьте по умолчанию (Framework: Next.js).
3. **Deploy**.

Или из терминала: `npx vercel` (в первый раз попросит войти в аккаунт).

## Docker (свой сервер / VPS)

```bash
docker compose up -d --build        # http://localhost:3000
PORT=8080 docker compose up -d      # на другом порту
docker compose down                 # остановить
```

Образ собирается из `Dockerfile` (standalone-сборка Next.js, Node 22 Alpine).

## Что поменять перед показом

- Название платформы: `PLATFORM_NAME` в `lib/data.js`
- Меню, районы, стартовые заказы и отзывы: `defaultState()` в `lib/data.js`
- Плейсхолдеры `[АДРЕС]` в данных
